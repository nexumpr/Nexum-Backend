- **Procedimiento para cerrar SRC-01:** recibir fuente original; generar matriz pantalla → acción → contrato por ID; clasificar delta como corrección o nuevo E076+; RFC y Gate de cambio; mantener `OpenAPI` / pruebas / IAM / DynamoDB / costos sincronizados. El equipo móvil solo aporta requisitos; no aprueba ni valida backend como gate.
- **Integridad del snapshot:** el archivo `BASELINE_SHA256.json` fija los hashes del SDD de referencia, excluido él mismo para evitar autorreferencia; `validar_sdd_integral.py` detecta desviaciones locales. Es un control documental, no una firma criptográfica de un tercero.
